# グラスソリティア — Glass Solitaire

Meta Ray-Ban Display 用の**クロンダイク・ソリティア**。山札・捨て札・組札4つ・場札7列を 600×600 の画面にまるごと収めた、一人遊びのカードパズル。D-pad でカーソルを動かし、タップでカードをとって、**緑に光る置ける場所**でもう一度タップするだけ。もとの場所でもう一度タップすれば**自動で置いてくれる**ので、グラスの少ない操作でもテンポよく遊べる。裏向きのカードがすべてめくれたら、残りのカードが**組札へ次々と飛んでいく**クリア演出つき。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-klondike.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / 静的サイト）

## 特徴

- **遠目でも読めるカード** — 小さめのカードでも、左上にランク・右上にスートを大きく表示。赤スート（♥♦）は明るい赤、黒スート（♠♣）は白系で描画（加算式ディスプレイでは黒が見えないため）
- **置ける場所をハイライト** — カードをとると、置ける組札・列が緑に点滅。とったカードは黄色の枠
- **もとの場所でタップ＝自動で置く** — 組札に置けるなら組札へ、なければ置ける列へ
- **自動で組札へ・自動仕上げ** — メニューの「自動で組札へ」で置けるカードをまとめて移動。裏向きがなくなると残りを自動で組札へ飛ばしてクリア
- **1手もどす** — メニューからいつでも（最大200手）
- **1枚めくり／3枚めくり** — タイトルやメニューで切替（3枚めくりは捨て札を扇状に表示）
- **手数・時間・記録** — 勝利数、プレイ数、ベストタイム・ベスト手数を保存。とちゅうのゲームも保存され、タイトルの「つづきから」で再開

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ。「めくり枚数」の行は←→（またはタップ）で1枚／3枚を切り替え |
| 場（列） | ←→で列を移動、↑↓で列の中の表向きカードをえらぶ（いちばん上でさらに↑で山札・捨て札・組札の段へ） |
| 上の段 | ←→で山札・捨て札・組札を移動、↓で場へ、↑で「≡ メニュー」 |
| とる・置く | タップでとる → 緑に光る場所でタップして置く。もとの場所でタップ＝自動で置く、山札でタップ＝とりけし |
| 山札 | タップでめくる（からっぽならタップで捨て札を山札にもどす） |
| メニュー | ↑↓でえらんでタップ（「← もどる」「1手もどす」「自動で組札へ」「新しいゲーム」「めくり枚数」「つかいかた」「タイトルへ」） |
| つかいかた | タップで「← もどる」 |
| PC確認用 | Escape でひとつ前の画面へ（カードを持っているときはとりけし）、クリックでカーソル移動＋タップ（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けるとデモ（録画用）。タイトルで「新しいゲーム」をタップすると、固定シードの配り札を自動プレイする（最初の数手はカーソル操作を見せ、その後は早送り→組札へ飛ぶクリア演出まで。記録は保存しない）。`?seed=N` で配り札を固定できます。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%82%BD%E3%83%AA%E3%83%86%E3%82%A3%E3%82%A2&appUrl=https%3A%2F%2Fglass-klondike.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスソリティア`、URL `https://glass-klondike.vercel.app` を入力。
